# Previous downloaded 3D printer (retained alternative)

- Source: https://grab3d.com/models/electronics/3d-printer/
- Download: https://grab3d.com/dl/3d-printer/3d-printer-light.glb
- Creator: Grab3D, Cozy PC Parts Kit
- License: CC0 1.0; see `3d-printer-LICENSE.txt`.
- File: `3d-printer.glb`, lightweight variant, 12,841 triangles with embedded textures.
- No external texture or decoder downloads are required.

The original GLB is unchanged and retained as an alternative. The homepage
currently uses a procedural metallic printer built in `PrinterScene.tsx`;
it does not load this GLB. Reduced-motion preferences disable automatic
animation; dragging still rotates the camera.
